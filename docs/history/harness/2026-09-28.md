## Deterministic RA2 production tests (preview.10 China flake)

### What We Fixed

- China's exact-package production test timed out in its six-mover water
  phase on the first preview.10 attempt and passed unchanged on rerun.
  Reproduced locally with per-poll water traces
  (`artifacts`-style evidence under the worktree's `.artifacts/china-diag/`).
  Two independent causes, both now removed:
  - **Wall-clock deadline.** The 140 s limit ran from process launch while the
    fixture plays at normal speed. Start-up alone took ~15 s on an idle host
    and 30–45 s when four fixtures started together, so identical matches
    passing at tick ~2600 needed 139–156 s; three of four parallel runs would
    have timed out in the water phase, the last phase. Budgets are now game
    ticks (the same 140/160 s of game time: 3,500/4,000 ticks); wall clock is
    only a 900 s hang guard reported separately.
  - **Crossing traffic.** Ships routed to farther cells nudge an idle, arrived
    ship off its destination (`Mobile.OnNotifyBlockingMove` → `Nudge`), and a
    mover whose final cell is momentarily occupied ends its move one cell short.
    Every traced China run had two ships nudged after arrival; 4–7 of 12 runs
    had a ship stop one cell short, which the old sampled check could never
    recover from. `ExactMoveCheck` records the first exact arrival and repeats
    the same move (at most three times, recorded with tick and cell) for an
    actor idle short of a destination it has not reached. Same units, same
    real water, same exact cells; nothing is teleported.
- A rarer start-up failure ("Could not find map" before the first tick) was
  traced to `Path.resolve()` returning an extended-length `\\?\C:\…` path when
  another process was creating the output's parent directory. The engine
  appends `maps/ra2/…` with forward slashes to that support directory, which
  extended paths do not normalize. All six such failures in 113 launches had
  the prefix and none of the others; an explicit `\\?\` output reproduces it
  every time. Fixtures now use `absolute_path()`.
- The validators now run on Windows: `Content` is linked with an NTFS junction
  when symlinks need a privilege the session does not hold.
- Iran and Türkiye shared the pattern and use the same helper
  (`scripts/native_fixture.py`).

### Verification

- Final code (`1aa28ab`), four fixtures in parallel, output parents created
  concurrently: China **12/12** (ticks 2,550–2,700 of 3,500; 7 runs needed one
  repeated order, each from one cell short), Türkiye **10/10** (1,330–1,400),
  Iran **10/10** (380–430). No start-up failures. Evidence:
  `.artifacts/flake-1aa28ab/` and `.artifacts/flake-1aa28ab-*.log` in the
  harness worktree. Earlier batches on intermediate commits are retained
  beside them (`flake/`, `flake-final/`, `flake-b3b3ee7/`), including the
  failures that led to the path fix.
- Development build: engine `5ddc34cb91` built in the worktree (zero warnings,
  zero errors) with the RA2 overlay from `scripts/prepare-local-ra2.py`. This
  is not a packaged payload; re-run on the next candidate (checklist F2).

## RA2 spectator and replay crash

### What We Fixed

- Every RA2 spectator view crashed on its first frame with `Sprite '/' was not
  found`. The pinned upstream observer layout declares `Label@LABEL` in the
  shroud selector, but the engine's `ObserverShroudSelectorLogic` requires a
  `LabelWithTooltipWidget`; the logic failed before binding the flag image.
  The compatibility patch now declares `LabelWithTooltip@LABEL` with the same
  tooltip container/template as the other observer labels. Found by the
  bot-vs-bot harness (the host spectates); after the fix RA2 bot matches
  complete and their replays play back exactly.

## Bot-vs-bot balance harness and September baseline

### What We Built

- `scripts/balance_harness.py` (`plan`, `run`, `report`, `replay`) with
  `scripts/balance_telemetry.lua` and `scripts/balance_campaigns.json`.
  Seeded schedule of every faction pairing in both slot/spawn orientations
  across maps, bot profiles and replicates; one private headless process and
  support directory per match; resumable; replays, telemetry, `summary.json`
  and `report.md`. Metrics: win rate per faction and pairing with 95% Wilson
  intervals, match length, economy checkpoints, production/losses by role,
  value destroyed/lost, stalled production, idle armies, crashes/hangs/Lua
  errors. Unthrottled simulation via a private manifest copy (per-tick
  simulation unchanged): a 15-minute match takes ~40 s.
- `replay` plays a match back with its saved map and requires the identical
  telemetry stream.

### Key Decisions

- No rules were edited. Harness-private changes are limited to map copies
  (slot locks, the telemetry script, the passive `ScriptTriggers` trait RA2's
  world lacks) and a manifest copy with a 1 ms default timestep.
- No engine change: the engine cannot be seeded, so the campaign seed fixes
  the schedule and orientation; each match's engine seed is recorded from its
  replay. A launch seed for the server RNG and the bots' local RNG is the
  recommended follow-up.
