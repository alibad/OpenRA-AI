One RTS AI product. Two ways to play.

Windows and the browser game are live. Neither requires owning Red Alert or Red Alert 2.

Downloadable RTS

Windows 0.4.0-alpha.1 / public alpha

Download Windows
  • One entry: RTSAI.exe
  • In-game choice: Classic / Isometric
  • 16 country choices, six campaigns
  • Native bots; optional local AI companion
  • EXE installer or portable ZIP, unsigned

Classic uses the shared modern army on a rectangular grid. Additional historical Classic mechanics and presentation remain to be ported.

Mac: build and acceptance later on the owner's Mac.

Web RTS

Static browser game / live

Play online
  • OpenRA simulation runs in your browser
  • 16 countries and six missions
  • Direct two-player peers, chat and optional video/audio
  • Manual connection codes; no owned room server
  • AI tactics, drills, workshop, saves and replay coaching

Browser Classic and cross-network peer acceptance remain pending. Restrictive networks can block direct peers; no TURN relay is included.

A model co-commander requires the local companion and optional models.

Your Windows test

  1. Choose Windows at rtsai.net/download.
  2. Verify its checksum. This alpha is unsigned; follow the download page's Windows instructions.
  3. Install with No AI for the first pass, then launch RTS AI.
  4. Open Game modes, choose Classic or Isometric, and start a skirmish in each.
  5. Try campaigns and optional local AI when ready.
