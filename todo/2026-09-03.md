# 2026-09-03

## What we built

- An optional native Red Alert 2 preview for Apple Silicon Macs, using the
  player's owned Steam artwork instead of a paid Windows compatibility trial.
- Real RA2 countries, isometric terrain, voxel vehicles, Allied/Soviet UI and
  base building through the OpenRA RA2 mod, rather than describing an
  RA2-inspired capability pack as the full game.
- A separate Applications entry and private settings/content/save directory,
  keeping the working OpenRA AI installation intact.
- A repeatable pinned-source build with verified downloads, safe game-data
  import, explicit version information and no bundled proprietary game files.

## What we fixed

- Adapted the older RA2 mod to our current engine, including resource docking,
  voxel previews/rendering, synchronization fields, map formats and lobby setup.
- Fixed crashes opening settings, starting skirmishes and viewing the in-game
  menu; checked country selection, a fresh human-controlled match, MCV
  deployment and successful power-plant production/placement.
- Prevented incomplete AI settings from appearing functional in this preview.
- Preserved macOS signatures when copying the preview into Applications.

## Key decisions

- Keep the engine submodule pinned; never silently switch it to the upstream
  mod's older engine or overwrite another session's work.
- Clearly identify this as a local RA2 skirmish preview, not an official
  release or a feature-complete reproduction. Companion, voice, AUTO,
  original campaigns and Yuri's Revenge still need separate integration.
- No CrossOver, no GitHub Actions, no public release or website changes.
- Validation includes the native build, all included map/rules checks,
  safe-import regression tests and interactive Mac smoke testing. Upstream
  localization warnings remain; ad-hoc signatures are not notarization.
- Verified 28 maps, 10 preview regression tests, and 508 engine tests
  (2 pre-existing skips). The isolated engine test run needed the source
  fixtures linked into its output layout; the corrected run passed.
- The native builds have no compiler warnings or errors. RA2 rules validation
  reports 793 upstream warnings, primarily missing or unused translations.

## Breaking changes

- None for the existing OpenRA AI application or public releases.

## Integrated RA2 and shared assistant follow-up

- The Mac packager now includes RA2 alongside World War III in one OpenRA AI
  app, with a remembered native game selector and shared assistant/model settings.
- RA2 uses its own unit names and isometric bridge coordinates. Native AUTO
  profiles deploy the MCV and handle real-time economy, production and combat.
- The packaged launcher still waits for companion health before opening the
  game; cleanup now follows child processes instead of only the launcher PID.
- Owned Steam/preview RA2 data can be imported into the shared library without
  overwriting different files or bundling proprietary archives.
- Fixed fresh-profile RA2 map-folder resolution and off-map prison fences that
  caused frozen-under-fog startup crashes. All 27 playable maps passed isolated
  headless startup/AUTO deployment checks.
- Shared voice labels and the always-visible, configured Ask shortcut are now
  included in the RA2 HUD. Local Whisper readiness was confirmed on this Mac;
  end-to-end physical shortcut/audio verification is still a release gate.
- Verification: 191 companion tests, 513 engine tests (two existing skips),
  shell syntax checks and whitespace validation passed. Live Soviet AUTO built
  power and a refinery and continued production.
- The five custom factions remain intact in World War III. Porting their
  distinct rosters/abilities to RA2 is not complete; asset reuse needs a product
  decision. Original campaigns and Yuri's Revenge remain outside this preview.
- No public release, website change, Windows RA2 build or GitHub Actions change
  is implied by this integration commit. Mac packaging validation follows below.
