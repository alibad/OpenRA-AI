# 2026-08-15

## What We Built

- Direct mission launches now include an opponent by default, while a normal macOS app launch opens the main menu so players choose when to start a match.
- Generated Earth missions now activate their authored objectives, briefing text, phase updates, and victory/defeat resolution in-game.
- macOS release validation now exercises the signed companion and verifies the launcher behavior from the mounted disk image.

## What We Fixed

- Matches no longer remain permanently in progress after the opposing force has been eliminated.
- Local ad-hoc macOS builds no longer fail after signing because of an inappropriate hardened-runtime requirement.
- Release builds now reject generated missions whose runtime files exist but are not actually connected to the map.
- A clean macOS checkout now builds the native map generator before creating its bundled sample mission, making the documented release command reproducible without leftover development binaries.

## Key Decisions

- Keep the bundled Riyadh mission available through an explicit direct-launch option instead of starting it every time the app opens.
- Require the engine's standard campaign runtime alongside generated mission rules so objective handling remains compatible with native OpenRA behavior.
- Preserve hardened-runtime signing for Developer ID releases while using compatible ad-hoc signing for local validation builds.

## Breaking Changes

- None.
