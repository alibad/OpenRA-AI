# 2026-08-31

## What We Built

- macOS now has an in-game Local AI Pack setup flow. **Settings > AI > Models**
  downloads the pinned 1.8 GB model set, verifies every byte count and SHA-256,
  starts the signed local gateway, and resumes interrupted downloads safely.
- The Mac package now carries native Apple Silicon llama.cpp and whisper.cpp
  servers plus the local speech runtime. llama.cpp comes from an exact pinned
  upstream binary release; whisper.cpp is built locally from its exact pinned
  source release because upstream does not publish a Mac server binary.

## What We Fixed

- Pressing Hold to Ask before local voice is ready now opens a native setup
  invitation instead of failing silently. It explains the optional pack size,
  starts the download only after the player selects **Install Local AI Pack**,
  and points to **Settings > AI > Models** for background progress. Downloading,
  model-startup, unsupported, and retry states each receive actionable copy.
- **Settings > AI > Voice** now leads with the actual configured Hold to Ask
  binding. A default Mac install says `HOLD OPTION+SPACE TO TALK`, while a
  remapped binding updates the instruction automatically.
- The AI diagnostic no longer exposes an internal localhost 502 when Local AI
  is absent. It directs the player to install the pack, and the diagnostic
  remains disabled until the selected local route is ready.
- Local Whisper and Local Voice are no longer presented as operational merely
  because the companion control server is healthy. The Models screen reports
  not installed, downloading, verifying, loading, ready, and retry states.

## Key Decisions

- Model files remain outside the signed app so the DMG stays practical. The app
  ships the small signed runtimes and installs only checksum-pinned model data
  into the user's OpenRA AI support directory.
- Native gameplay AI, deterministic alerts, and AUTO do not depend on the model
  pack and remain available before or during model installation.

## Breaking Changes

- None. Existing remapped AI hotkeys and model settings remain valid.
