# 2026-09-21

## Mac push-to-talk release and truthful voice state

- Fixed the live failure where Option+Space could remain stuck on
  `LISTENING • RELEASE TO ASK`: the engine now tracks physical key state before
  UI dispatch and uses a per-frame release watchdog, so releasing either Space
  or the required Option modifier ends capture even if another widget consumes
  the key-up event.
- Whisper annotations such as `[BLANK_AUDIO]`, `[silence]`, `(music)`, and
  `[background noise]` are no longer displayed as the player's words or sent
  to chat. A capture with no recognized speech now says `NO VOICE DETECTED`
  and points the player to microphone access.
- Rapid voice retries now release every generation's user-turn lock. Replacing
  an earlier capture can no longer silently suppress later answers and live
  battlefield events.
- Transient voice states no longer turn the native AUTO assistant off. Only an
  explicit strategy-qualified manual state may disable AUTO, so the HUD and
  delegated native brain remain synchronized through no-speech and retry
  flows.
- Regression evidence: 258 companion tests pass with two platform skips; all
  7 AI-control engine tests pass; the final full engine suite passes 544 tests
  with two PNG parser skips, and the engine builds with zero errors. Direct
  capture verified the selected `MacBook Pro Microphone` produces a non-zero
  signal.
- Built and installed `0.1.0-alpha.18-ra2-preview.13` from product commit
  `f82aaf5` and engine commit `7903cb4c8b2edb92b87cbbb97082ccb32146ff2b`.
  Apple notarization submission `408ef53e-6eb8-40b4-96d8-b3e7ea8c9416`
  was Accepted. The stapled DMG passes the read-only package smoke test and has
  SHA-256 `6cd8d8eb8c76714faf5a826d045d53e5d1a7ae3560b6d1d79d6015026743438f`.
- The exact notarized payload is running from `/Applications/OpenRA AI.app`.
  Its companion reports the preview.13 version, AUTO enabled, control ready,
  the local router reachable, and Local Whisper ready. The previous preview.12
  app remains recoverable under `artifacts/installed-app-backups`.
