# 2026-09-02

## What We Built

- Local AI now offers an Automatic default that reserves resources for the
  game. Balanced includes image understanding; Lightweight saves the image
  download and uses structured battlefield state. Both include English voice
  input and spoken replies, with clear setup/readiness information.
- Players can detect compatible models already in LM Studio from Advanced
  settings and explicitly apply the proposed configuration. LM Studio remains
  optional; discovery never installs software or downloads a model.
- The opening menu exposes the active Experience, enabled capability count,
  and modern factions. A match-start notification makes the active experience
  visible without interrupting play.

## What We Fixed

- Removed misleading Local Small/Local Coder choices from the default settings
  experience and stopped Reset from selecting cloud voice routes by accident.
- Capped inference CPU threads and concurrency, and clarified command prompts
  so forbidden actions are not simultaneously advertised as allowed commands.
- Corrected final Mac signing order so the apphost keeps its required .NET JIT
  entitlement after the app is sealed.

## Key Decisions

- World War III remains the fresh-install default, including Saudi Arabia,
  Yemen, Turkey, Iran, and China and the enhanced capability portfolio. An
  existing player's explicit custom/classic choice is preserved. Red Alert 2
  and Yuri's Revenge units/artwork are not bundled or claimed to be present.
- The two initial resource profiles share one qualified model. A newer 0.8B
  candidate failed focused command checks and was not promoted. Catalogue
  changes require local validation and a deliberate app update.
- Model preference changes take effect next launch. Running matches, other
  release worktrees, published downloads, and GitHub Actions remain untouched.

## Breaking Changes

- None. Existing model route IDs and remapped shortcuts remain valid.
