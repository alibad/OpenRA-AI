# 2026-08-28

## What We Built

- Official Windows releases now have an optional Authenticode stage that signs and verifies the companion, local runtime, OpenRA game/server/utility executables, product launcher, NSIS uninstaller, and final setup executable without accepting certificate files or passwords from the repository.
- The public website now reads downloads from a committed release manifest, so GitHub API timeouts cannot make the download page disappear or silently change versions.
- The website development and Vercel toolchain is pinned to Node 22.22 and npm 11.19 for repeatable clean installs.

## What We Fixed

- The macOS launcher now starts the companion first, waits for its health endpoint, and launches the game only after AUTO is available. Closing the game still cleans up the companion.
- AUTO displays `STARTING…` until the game receives the companion's real status instead of briefly claiming AUTO is off.
- macOS uses Option+Space for Hold to Ask, while Windows keeps Ctrl+Space. The displayed shortcut follows the configured AI Assistant hotkey, and all AI shortcuts remain remappable.
- Current-engine macOS packages now include the hardened-runtime JIT entitlement required by .NET 10 and relocate Homebrew's Brotli dependency so the app does not depend on the release host.
- Generated Earth missions wait for both players' starting units before evaluating defeat, preventing the sample battlefield from declaring an immediate loss on its first simulation tick.
- Native map generation once again supplies hidden/default generator options required by the current engine main branch.

## Key Decisions

- Integrated the current engine main line after reviewing its upstream merge instead of leaving the product pinned to the alpha.13 engine snapshot.
- The published alpha.13 Windows installer remains explicitly labeled unsigned. A future Windows package cannot be called official unless every required signature and trusted timestamp verifies on Windows.
- Release discovery is updated deliberately with the local manifest synchronization command; the production download page makes no runtime GitHub Releases API request.

## Breaking Changes

- None. Existing AI Assistant hotkey customizations remain valid; only the default macOS Hold to Ask shortcut changes to Option+Space.
