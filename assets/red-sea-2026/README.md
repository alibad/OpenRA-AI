# Red Sea 2026 asset sources

This directory holds editable source and provenance notes for the vertical slice.
Runtime-ready assets are installed under `engine/openra/mods/ra/bits` while the
prototype is integrated with the Red Alert ruleset.

## Key art

- `red-sea-key-art.png`
- Generated with the built-in OpenAI image-generation tool on 2026-08-11.
- Original text-free visual anchor for lighting, palette, coastal geography,
  drone silhouettes, air-defense shapes, and loading-screen composition.
- The equipment is intentionally generic rather than a pixel-level copy of a
  manufacturer's design.

## Sound effects

The first interceptor, mobile-launch, and drone-strike effects are generated by
`scripts/generate-red-sea-sfx.py`. They use deterministic synthesis and no
sampled recordings, news audio, manufacturer media, or third-party libraries.
