# Red Sea 2026 asset sources

This directory holds editable source and provenance notes for the vertical slice.
Runtime-ready assets are installed under `engine/openra/mods/ra/bits` while the
vertical slice is integrated with the Red Alert ruleset.

## Key art

- `red-sea-key-art.png`
- Generated with the built-in OpenAI image-generation tool on 2026-08-11.
- Original text-free visual anchor for lighting, palette, coastal geography,
  drone silhouettes, air-defense shapes, and loading-screen composition.
- The equipment is intentionally generic rather than a pixel-level copy of a
  manufacturer's design.

## Sound effects

The first interceptor, mobile-launch, and drone-strike effects are generated by
`scripts/generate-red-sea-sfx.py`. They use deterministic synthesis and no
sampled recordings, news audio, manufacturer media, or third-party libraries.

## Unit sprite sources

Early flat-chroma studies remain in `sprite-sources/` as concept provenance,
but no moving runtime unit rotates one of those bitmaps. The production actors
are deterministic fixed-camera models defined in
`scripts/red_sea_directional_vehicle.py`. It renders 32 classic Red Alert
perspectives for every ground body, independent M1A2S/air-defense/technical
turrets, loaded and empty launcher states, and 16 authored drone views.

The generated frame pass also creates matching directional scorched wrecks for
all four ground vehicles. This prevents the M1A2S from falling back to the stock
2TNK husk and gives the other custom vehicles persistent destruction states.

The M1 study contains dedicated 16-view isometric hull and turret references
plus their exact prompts in `m1a2s-directional-prompts.md`. These informed the
fixed-camera geometry but are not directly rotated into runtime frames.

The combat pass adds three independently generated flat-chroma effect masters:
`m1-muzzle-source-v2.png`, `m1-impact-source-v2.png`, and
`drone-impact-source-v1.png`. They are converted into an eight-facing muzzle
animation, a nine-stage tank-shell impact, and an eleven-stage drone impact by
the same deterministic sprite build. The source prompts requested original,
isolated late-1990s RTS effects with no vehicles, people, scenery, text, or logos.

`icon-sources/` contains five dedicated 4:3 production-cameo illustrations,
generated with the built-in OpenAI image-generation tool and benchmarked
against the closest native 64x48 Red Alert icon. The exact prompt set is stored
in `icon-sources/production-icon-prompts.md`. The deterministic builder crops,
grades, labels, palette-quantizes, and packages each one into an opaque one-frame
`*icon.shp`; battlefield animation frames are never reused as sidebar art.

`scripts/build-red-sea-sprites.py` performs directional and wreck rendering,
effect chroma cleanup, contact-shadow construction, native Red Alert palette
quantization, icon construction, and indexed frame export. OpenRA.Utility
combines those frames into the runtime SHPs.

## Unicode font fallback

The Red Alert UI keeps FreeSans as its primary font and adds Noto Sans Arabic as
a fallback for Arabic and Persian glyphs. The font files are from the official
Noto Arabic project, version 2.013, and are licensed under the SIL Open Font
License 1.1. The license text is stored at `licenses/NotoSansArabic-OFL.txt`.

## Synthetic voice provenance

`voice-provenance.json` records the exact Arabic and English line, locale,
generic neural voice, duration, format, and synthetic-voice disclosure for
every generated file. The voices do not imitate a real person. Mission radio is
mastered separately from short unit acknowledgements.
