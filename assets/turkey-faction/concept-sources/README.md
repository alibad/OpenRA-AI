# Turkey faction concept source

`turkey-roster-concept.png` is an original generative art-direction board
created for this faction on 2026-08-12. It is retained as design provenance;
it is not sampled, rotated, or shipped as directional unit artwork.

- Generator: OpenAI image generation tool
- Prompt intent: fictional combined-arms silhouettes, no exact real platforms,
  logos, flags, real individuals, or political leaders
- SHA-256: `7eb55e766054a2e0732c7752e6e3a5c6763a647975c42df60de234c12b8fdd5e`
- Playable art path: deterministic fixed-camera geometry in
  `scripts/turkey_directional_assets.py` plus direct per-facing infantry
  drawing in `scripts/build-turkey-sprites.py`

The concept generator added presentation text despite the no-readable-text
request. That text remains quarantined in this provenance-only source and is
not reused in any shipped cameo, icon, mission, or UI asset.
