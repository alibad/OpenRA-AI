# 03: Haitan Network

This is a fictional combined-arms exercise set on a native-generated island map.
The player restores a command network, moves amphibious IFVs through a verified
water gate, and coordinates land, air, missile, drone, and naval forces against
the fictional Obsidian Directorate.

No real attack, real operation, real leader, or real force disposition is
represented. See `docs/china-faction-research.md` for the dated sources and the
capability-to-gameplay translation boundary.
