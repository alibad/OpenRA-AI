# China AI build-contract fixture

Hidden from normal lobbies (`Shellmap`). This deterministic fixture gives the
normal AI ample cash, locks it to China, exercises native base construction,
preplaces the infantry/air/naval/high-tech production gates so every unit queue
is exercised in one bounded run, and weights every China combat unit to a build limit. It is packaged only by
the automated AI verifier and is not a playable mission.
