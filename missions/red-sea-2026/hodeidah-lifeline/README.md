# Hodeidah Lifeline mission source

This directory contains the authored source for the second Red Sea 2026
vertical-slice mission. It reuses the deterministic 96x96 desert terrain grid
but defines a new playable Yemen base, two-stage convoy flow, surveillance
dispersal mechanic, attack schedule, objectives, localization, and radio.

Build both Red Sea mission packages with:

```powershell
scripts\build-red-sea-mission.py
```

The factual cutoff is 2026-08-11. Force composition, routes, positions, timing,
and outcomes are fictional gameplay abstractions.
